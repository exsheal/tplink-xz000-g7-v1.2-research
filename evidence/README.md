# Seçilmiş statik kod izleri

Bu parçalar hesap, format ve sürücü yollarının incelenen binary’deki yorumunu destekler. Tam proprietary binary/disassembly veya özel runtime dump yayımlanmaz. Ayıklanmış alanlar WITHHELD olarak gösterilir; adresler 2025 build bağlamındadır.

| Dosya | Konu |
|---|---|
| [password-identity.txt](password-identity.txt) | Varsayılan parola üretimi ve flash kimlik okuyucuları |
| [gcs-vlan.txt](gcs-vlan.txt) | GCS/OMCI VLAN uygulanması |
| [gpon-status-auth.txt](gpon-status-auth.txt) | GPON durum, optik ve auth setter/getter yolları |
| [firmware-upgrade.txt](firmware-upgrade.txt) | IMAGE_TAG ve update kontrolü |
| [crypto-verification.txt](crypto-verification.txt) | MD5/RSA yollarının kanıt ve sınırları |
| [gcs-heap-layout.txt](gcs-heap-layout.txt) | Serileştirilmiş GCS yapı düzeni |
| [bank1-auth-initialization.txt](bank1-auth-initialization.txt) | Eski 2025 bankındaki GPON auth init davranışı |

Kod yolunun bulunması mevcut operatör profiliyle başarılı işlem yapıldığı anlamına gelmez. [Kapsam ve yöntem](../docs/01-kapsam-ve-kanit.md).
